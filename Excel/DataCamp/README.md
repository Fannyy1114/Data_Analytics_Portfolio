# DataCamp

This folder documents my learning journey through DataCamp courses and complementary learning resources.

The notes, exercises, and practice files in this folder are created to reinforce my understanding of data analytics concepts through hands-on practice. Rather than simply completing online courses, I summarize key concepts, document my thought process, and apply what I learn through additional exercises and small projects.

## Topics Covered

- SQL
- Python
- Pandas
- Data Cleaning
- Data Manipulation
- Data Visualization
- Statistics (as applicable)
- Business Analytics

## Learning Approach

Most of my learning follows a structured, project-based approach. For each topic, I aim to:

- Learn the core concepts
- Complete guided exercises
- Take personal notes and summarize key ideas
- Apply the concepts through additional practice or portfolio projects

This helps me build practical skills instead of only finishing online courses.
